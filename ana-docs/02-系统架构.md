# 二、系统架构

## 2.1 三层架构总览

```
┌──────────────────────────────────────────────────────────────────┐
│                     Vue 3 前端 (Element Plus)                     │
│  发布中心 · 账号管理 · 素材中心 · 任务中心 · 仪表盘 · 草稿箱    │
│  路由: vue-router (hash) · 状态管理: Pinia · HTTP: Axios          │
│  构建: Vite 6 · 样式: SCSS + Element Plus 主题系统               │
│  端口: 5173 (dev) / 静态文件由 Flask 托管 (prod)                 │
├──────────────────────────────────────────────────────────────────┤
│                    Python Flask 后端 (Waitress)                    │
│  主入口: app.py · 扩展 API: ext_api (阶段二) · 数据库: SQLite    │
│  异步任务队列: asyncio.Queue + ThreadPool · SSE 实时推送          │
│  FFMpeg 服务 · 分片上传 · 素材管理 · 存储抽象层 (Local/S3)       │
│  端口: 5409 (默认)                                                │
├──────────────────────────────────────────────────────────────────┤
│                    平台自动化层 (Playwright + CloakBrowser)        │
│  19 个平台实现，按 Registry 模式注册                              │
│  浏览器工厂: _browser.py (CloakBrowser 隐身 Chromium)             │
│  登录/发布/校验: 各平台独立 platform.py 继承 BasePlatform         │
├──────────────────────────────────────────────────────────────────┤
│                    TypeScript MCP 服务 (可选)                      │
│  MCP 协议对接 AI Agent (Claude / ZCode)                          │
│  提供工具: 发布/账号/草稿/素材/任务/设置/更新日志                │
│  Stdio + SSE 双传输模式 · 可选 Token 鉴权                        │
└──────────────────────────────────────────────────────────────────┘
```

## 2.2 架构设计原则

### 2.2.1 本地优先

所有数据存储在本地 SQLite 数据库中，不上传任何用户数据到第三方服务（除发布行为本身外）。数据目录结构：

```
data/
├── db/database.db        # SQLite 数据库
├── cookiesFile/          # 平台登录 cookie 文件 (.json)
├── cookies/              # 旧版 cookie 存储（兼容）
├── uploads/              # 上传文件存储
├── thumbnails/           # 封面缩略图
├── upload_chunks/        # 分片上传临时文件
├── logs/                 # 运行日志
└── materials/            # 素材库文件
```

### 2.2.2 可扩展平台架构

平台实现采用 **Registry 模式**：`backend/impl/registry.py` 维护 `platform_id → class` 的映射。新增平台只需创建 `impl/<name>/platform.py` 并继承 `BasePlatform` 即可。

```python
# registry.py 核心 — 自动化注册
def _populate_registry() -> None:
    imports = [
        (1, ".xiaohongshu.platform", "XiaohongshuPlatform"),
        (2, ".channels.platform", "ChannelsPlatform"),
        # ... 共 19 个平台
    ]
    for pid, mod_path, cls_name in imports:
        mod = importlib.import_module(mod_path, package=__package__)
        cls = getattr(mod, cls_name)
        register(pid, cls)
```

### 2.2.3 前后端分离 + 同源部署

- **开发模式**：Vite 开发服务器 (5173) 代理 API 请求到 Flask (5409)
- **生产模式**：Flask 直接托管 Vite 构建后的前端静态文件，单端口部署

## 2.3 技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| 前端 | Vue 3 + Element Plus | UI 框架 |
| 前端 | Pinia | 状态管理 |
| 前端 | Vue Router (hash) | 前端路由 |
| 前端 | Axios | HTTP 请求 |
| 前端 | Vite 6 | 构建工具 |
| 前端 | SCSS | 样式预处理 |
| 后端 | Python Flask 3 | Web 框架 |
| 后端 | Waitress | WSGI 生产服务器 |
| 后端 | SQLite | 数据库 |
| 后端 | CloakBrowser | 隐身浏览器自动化 |
| 后端 | Playwright (via CloakBrowser) | 浏览器操作 |
| 后端 | FFMpeg | 视频处理 |
| 后端 | OpenCV / Pillow | 图片处理 |
| MCP | TypeScript + @modelcontextprotocol/sdk | AI Agent 对接 |
| MCP | sql.js | 直接读取 SQLite |
| 存储 | Local / S3 (boto3) | 文件存储抽象 |

## 2.4 通信协议

| 路径 | 协议 | 说明 |
|------|------|------|
| 前端 → 后端 | HTTP REST API | 常规 CRUD 操作 |
| 后端 → 前端 | SSE (Server-Sent Events) | 登录状态、任务进度实时推送 |
| MCP → 后端 | HTTP REST API | MCP 工具通过 HTTP 调用后端 |
| LLM → MCP | MCP 协议 (Stdio/SSE) | AI Agent 通过 MCP 协议调用工具 |
