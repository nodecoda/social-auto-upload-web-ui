## 3.2 后端分层架构

```
┌─────────────────────────────────────────────────────┐
│ 路由层 (Blueprint)                                   │
│  app.py, blueprints/*, ext_api/, routes/             │
├─────────────────────────────────────────────────────┤
│ 服务层 (Services)                                    │
│  publish_executor, draft_merge, ffmpeg_service,      │
│  image_service, duration_repair                      │
├─────────────────────────────────────────────────────┤
│ 平台自动化层 (Impl)                                  │
│  base_platform.py, registry.py, _browser.py          │
│  + 19 个平台实现                                     │
├─────────────────────────────────────────────────────┤
│ 基础设施层                                            │
│  storage/ (Local/S3), util/, conf.py, init_db.py     │
└─────────────────────────────────────────────────────┘
```

## 3.3 前端分层架构

```
┌─────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────┘
```

## 3.4 核心模块职责说明

| 模块 | 职责 |
|------|------|
| `impl/base_platform.py` | 定义所有平台的抽象接口：login / check_cookie / open_creator_center / sync_profile / publish_video / publish_note / publish_image / import_cookie |
| `impl/_browser.py` | CloakBrowser 浏览器工厂，统一创建浏览器、管理生命周期、监听关闭事件 |
| `ext_api/task_queue.py` | asyncio 任务队列（Worker 模式），支持并发控制、失败处理、进度追踪 |
| `ext_api/__init__.py` | 任务管理、发布历史、统计数据、SSE 实时推送（/api/v2 前缀） |
| `storage/` | 存储抽象，支持本地文件与 S3 两种后端，自动切换 |
| `services/draft_merge.py` | 草稿合并、发布参数构建（build_platform_kwargs） |
| `services/ffmpeg_service.py` | FFmpeg 封装（时长/尺寸/缩略图/转码） |
| `blueprints/materials_bp.py` | 素材管理（上传、分片、缩略图、时长识别） |
| `frontend/src/config/platforms.js` | 平台配置中心（前后端平台 ID 约定） |
| `backend-mcp/src/tools/` | MCP 工具实现（AI 自然语言驱动的发布能力） |
