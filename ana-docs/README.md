## 一句话总结

**千帆云递是一个本地优先、单用户的多平台社媒自动发布工具**：Vue 3 + Element Plus 前端提供统一发布界面，Python Flask + SQLite 后端负责任务编排与数据持久化，CloakBrowser（隐身 Chromium）+ Playwright 自动化层驱动 19 个平台完成真实网页登录与视频/图文发布，另提供可选 TypeScript MCP 服务让 AI Agent 通过自然语言调用整套发布能力。
