# 六、平台自动化详解

## 6.1 BasePlatform 抽象基类

所有平台实现都必须继承 `BasePlatform`（`backend/impl/base_platform.py`），并实现以下抽象方法：

```python
class BasePlatform(ABC):
    platform_id: int          # 平台 ID（1-19）
    platform_key: str         # 平台拼音 key（如 'douyin'）
    platform_name: str        # 平台中文名

    @abstractmethod
    async def login(self, id, status_queue, account_id=None) -> None:
        """执行平台登录，进度通过 status_queue 推送"""

    @abstractmethod
    async def check_cookie(self, cookie_file: str) -> bool:
        """校验保存的 cookie 是否仍有效"""

    @abstractmethod
    async def open_creator_center(self, cookie_file: str) -> None:
        """打开平台创作者中心 / 上传页面"""

    @abstractmethod
    async def sync_profile(self, cookie_file: str):
        """同步用户信息，返回 {name, avatar, stats}"""

    @abstractmethod
    def publish_video(self, **kwargs) -> bool:
        """发布视频，成功返回 True"""
```

## 6.3 平台 cookie 管理

### 6.3.1 登录后保存

```python
# 各平台 login 方法内（如 xiaohongshu/login.py）
# 1. 等待登录成功（检测 URL / 页面元素）
# 2. 获取 storage_state
storage_state = await context.storage_state()
# 3. 写入 data/cookiesFile/{account_id}_{platform_key}.json
with open(cookie_path, 'w') as f:
    json.dump(storage_state, f)
# 4. 更新数据库 user_info（status=1, filePath=cookie文件名）
```

### 6.3.2 Cookie 导入（import_cookie）

`BasePlatform.import_cookie` 提供 4 步进度流程：

```
Step 1: 解析 cookie 字符串 → storage_state (cookies, origins)
Step 2: 打开浏览器验证 cookie（有头）
Step 3: sync_profile 同步用户信息（昵称/头像/运营数据）
Step 4: 创建/更新 user_info 记录
```

`supports_cookie_import=True` 的平台重写 `_parse_cookie_to_storage_state`。

    case 4:  post_video_ks(...)
