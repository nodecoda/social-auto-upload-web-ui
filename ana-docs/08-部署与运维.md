# 八、部署与运维

## 8.1 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行时 |
| Node.js | 18+ | 前端构建 / MCP |
| FFmpeg | 任意较新版本 | 视频处理（时长/缩略图） |
| 系统 | Windows / macOS / Linux | 跨平台支持 |

## 8.2 启动方式

### Windows（.bat）

```bat
start.bat          # 标准启动
start-beta.bat     # Beta 版本启动
merge-data.bat     # 数据合并
```

### Linux / macOS（.sh）

```bash
start.sh           # 标准启动
start-macos.sh     # macOS 专用
start-beta.sh      # Beta 版本启动
update.sh          # 更新脚本
```

### 开发模式

```bash
# 后端
cd backend
pip install -r requirements.txt
python app.py            # 默认端口 5409

# 前端
cd frontend
npm install
npm run dev              # 默认端口 5173
# vite config 已配置代理到 5409

# MCP（可选）
cd backend-mcp
npm install
npm run dev
```

## 8.3 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `SAU_PORT` | 5409 | 后端监听端口 |
| `SAU_DATA_DIR` | `repo/data` | 数据目录（打包模式覆盖） |
| `FEEDBACK_API_BASE_URL` | `https://feedback.cjxch.com` | 反馈系统 API |
| `FEEDBACK_APP_KEY` | 内置 | 反馈系统密钥 |
| `FEEDBACK_APP_SECRET` | 内置 | 反馈系统密钥 |
| `FEEDBACK_API_TIMEOUT` | 10 | 反馈请求超时 |

## 8.4 生产部署

生产模式下 Flask 直接托管 Vite 构建产物：

```python
# app.py
FRONTEND_DIR = Path(__file__).parent.parent / "frontend"

@app.route('/')
def index():
    if FRONTEND_DIR.exists():
        return send_from_directory(str(FRONTEND_DIR), 'index.html')
```

单端口部署（5409 同时服务前端与 API），由 Waitress 提供 WSGI 服务。

## 8.5 数据备份与迁移

### 数据合并（Windows ↔ 多机）

`merge-data.sh` / `merge-data.bat` 提供多机数据合并能力（合并不同机器的 database.db + 素材）。

### 旧数据迁移

`scripts/migrate_legacy_data.py` 处理历史版本数据迁移。

### 增量 schema 迁移

`init_db.py` 的 `migrate_database()` 使用幂等方式（`ALTER TABLE ... ADD COLUMN` 失败忽略）逐步升级 schema。

## 8.8 已知限制与注意事项

1. **大文件内存读取**：`materials_bp.py` 使用 `file.read()` 一次性读入内存，≥10GB 文件可能 OOM（代码注释已说明）
2. **重试逻辑已禁用**：任务队列中失败任务立即标记 FAILED，不做自动重试（避免重复上传）
3. **代理兼容**：启动时清除 `ALL_PROXY`（CloakBrowser 不支持 SOCKS）
4. **平台风险**：自动化操作违反部分平台用户协议，使用时需自行承担风险
