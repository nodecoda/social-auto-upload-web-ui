# 一、项目功能概述

## 1.1 项目简介

**千帆云递（QianFan Sync）**，原名 `social-auto-upload-web-ui`，是一款一站式多平台社交媒体自动发布工具。它解决内容创作者「一份素材、多端分发」的核心痛点：用户只需在一个界面中拖入视频/图集、勾选目标平台与账号、填写一次标题/标签/封面，即可一键发布到多个平台。

项目源码托管于 GitHub：https://github.com/DevilJie/social-auto-upload-web-ui

## 1.2 核心功能

| 功能 | 说明 |
|------|------|
| **多平台一键发布** | 支持 19 个国内外主流平台，一次操作同步分发到多个账号 |
| **账号标签体系** | 账号支持多标签管理，按标签/渠道多维度筛选目标账号 |
| **定时发布** | 日历式排程，支持全量/增量两种批量定时应用模式 |
| **视频 + 图集双形态** | 既支持视频发布，也支持图文/图集发布（小红书、抖音、微博等） |
| **可视化封面编辑** | B站封面编辑器、多比例画幅、自动生成缩略图 |
| **任务中心** | 实时发布状态追踪，异步任务队列，失败重试 + 指数退避 |
| **素材中心** | 统一视频/图片素材库，按平台分类管理，支持分片上传与断点续传 |
| **渠道黑名单** | 全局屏蔽不使用的平台，多端联动过滤 |
| **视频校验** | 上传即识别时长/大小，前后端双重校验避免发布失败 |
| **反检测自动化** | CloakBrowser 隐身 Chromium，降低被平台识别为机器人的风险 |
| **AI Agent 启动** | 通过 MCP 协议对接 LLM，支持自然语言驱动的发布操作 |
| **草稿箱** | 保存发布参数为草稿，支持批量发布草稿 |
| **发布历史** | 完整记录每次发布的批次与明细，支持查看详情与重试 |
| **反馈系统** | 内置一键反馈功能，可向开发者提交问题与建议 |
